# Contributing

Read [AGENTS.md](AGENTS.md) and the [Git guide](docs/git-workflow.md).
Identify the track, evidence and expected behavior in each change. Add synthetic
tests for parsing and state behavior; never contribute biometric fixtures.
Run `make test` and document hardware tests separately. Include reproduction steps,
source revisions and limits. Preserve attribution and discuss license selection
before contributing code intended for redistribution. No contributor agreement or
project-wide license has been adopted yet.
